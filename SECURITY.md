# Segurança

Encontrou uma vulnerabilidade? **Não abra uma issue pública.**

Relate de forma privada pela aba [Security → Report a vulnerability](https://github.com/guilhermemcr1/BuildBass/security/advisories/new). Descreva o problema, como reproduzir e o impacto esperado. A resposta vem assim que possível, e o crédito pela descoberta é dado na correção, se você quiser.

Só a versão atual da branch `main` (e o que está em [buildbass.galarca.dev](https://buildbass.galarca.dev/)) recebe correções.
